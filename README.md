# Study Buddy Bot: Blood Circulatory System

## 1. Project Description
Study Buddy Bot is an educational learning project that helps students learn about the human blood circulatory system through questions and answers in Bahasa Melayu.

## 2. Objectives
- To help students understand the blood circulatory system.
- To provide simple and clear explanations about the circulatory system.
- To help students revise important science concepts.
- To encourage self-learning through questions and quizzes.

## 3. Bot Name
Study Buddy Bot: Blood Circulatory System

## 4. Target Users
Primary school students who are learning about the human blood circulatory system.

## 5. Main Topics
- Introduction to the Blood Circulatory System
- The Heart
- Blood Vessels and Blood Flow
- Components of Blood
- Blood Circulation and Healthy Lifestyle Practices

## 6. What My Bot Can Do
My bot can answer students' questions about the blood circulatory system and help them learn through simple explanations and quizzes.

## 7. Language
Bahasa Melayu

## 8. Learning Materials
This project contains 100 questions and answers about the blood circulatory system to support students' revision and understanding of basic science concepts.

## 9. How to Use
Students can read the questions and answers to review the topic, practise answering questions, and test their understanding of the blood circulatory system.

## 10. Educational Purpose
This project is designed for educational purposes to support science learning and independent revision.
